### 1.2 架构分层说明

| 层级 | 职责 | 关键组件 |
|------|------|----------|
| **用户交互层** | 用户界面和外部接入 | Web UI, CLI, API, Webhook |
| **API 网关层** | 请求处理和安全控制 | 认证、限流、路由、监控 |
| **Agent 层** | AI 智能处理 | Lead Agent, Sub-Agents, Skills |
| **业务服务层** | 核心业务逻辑 | 各功能模块服务 |
| **存储层** | 数据持久化 | 数据库、缓存、文件存储 |

## 4. DeerFlow 集成架构

### 4.1 DeerFlow 核心概念

| 概念 | 说明 | OpsPilot 对应 |
|------|------|---------------|
| **Lead Agent** | 主控 Agent，负责任务调度 | 需求接收和分发 |
| **Sub-Agent** | 专业 Agent，处理特定任务 | 5 个专业 Agent |
| **Skill** | 能力模块，定义处理方法 | 6 个运维 Skills |
| **Memory** | 记忆系统，保存上下文 | 知识和对话记忆 |
| **Tool** | 工具集，执行具体操作 | 搜索、文件、代码执行 |

### 4.3 Skills 配置

```yaml
# config.yaml
skills:
  paths:
    - skills/opspilot
    - deerflow/skills/public
  
  enabled:
    - requirement-analysis  # 需求分析
    - bugfix-solution       # Bug 修复
    - feature-design        # 功能设计
    - code-generation       # 代码生成
    - test-execution        # 测试执行
    - knowledge-retrieval   # 知识检索
```

### 4.4 Sub-Agents 配置

```yaml
# config.yaml
subagents:
  enabled: true
  max_concurrent: 3
  
  agents:
    - name: requirement_analyzer
      display_name: 需求分析 Agent
      skills: [requirement-analysis, knowledge-retrieval]
    
    - name: bugfix_agent
      display_name: Bug 修复 Agent
      skills: [bugfix-solution, code-generation, test-execution]
    
    - name: feature_agent
      display_name: 功能设计 Agent
      skills: [feature-design, deep-research]
    
    - name: codegen_agent
      display_name: 代码生成 Agent
      skills: [code-generation, test-execution]
    
    - name: test_agent
      display_name: 测试 Agent
      skills: [test-execution]
```

## 7. 扩展性设计

### 7.1 Skills 扩展

新增 Skill 只需：
1. 创建 `skills/opspilot/<skill-name>/SKILL.md`
2. 在 `config.yaml` 中启用
3. 关联到相应 Agent

### 7.2 Agent 扩展

新增 Agent 只需：
1. 在 `config.yaml` 的 `subagents.agents` 中配置
2. 指定关联的 Skills
3. Lead Agent 会自动发现和调度

### 7.3 存储扩展

- 支持替换数据库（PostgreSQL/MySQL/SQLite）
- 支持替换向量库（Milvus/Pinecone/Weaviate）
- 支持替换缓存（Redis/Memcached）
