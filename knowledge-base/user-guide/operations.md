# 操作指南

## 1. 项目管理

### 1.1 创建项目

**步骤：**
1. 在首页点击 **"新建项目"**
2. 填写项目信息
3. 点击 **"创建"**

**字段说明：**
| 字段 | 必填 | 说明 |
|------|------|------|
| 项目名称 | 是 | 唯一标识 |
| 描述 | 否 | 项目简介 |
| 仓库地址 | 否 | Git 仓库 URL |

### 1.2 编辑项目

1. 进入项目详情
2. 点击 **"设置"**
3. 修改相关信息
4. 点击 **"保存"**

### 1.3 删除项目

1. 进入项目设置
2. 滚动到页面底部
3. 点击 **"删除项目"**
4. 确认删除

⚠️ **警告**：删除项目会同时删除所有相关数据。

### 1.4 项目配置

**AI 配置：**
- 选择主要模型（GPT-4o、DeepSeek 等）
- 配置备用模型
- 设置温度参数

**审核配置：**
- 启用/禁用审核
- 设置审核人
- 配置审核规则

## 2. 需求管理

### 2.1 创建需求

**步骤：**
1. 进入项目
2. 点击 **"新建需求"**
3. 填写需求信息
4. 点击 **"提交"**

**需求类型：**
| 类型 | 说明 |
|------|------|
| Bug | 软件缺陷 |
| Feature | 新功能 |
| Task | 任务工单 |
| Improvement | 优化改进 |

### 2.2 编辑需求

1. 在需求列表找到目标需求
2. 点击进入详情
3. 点击 **"编辑"**
4. 修改后保存

### 2.3 需求状态

| 状态 | 说明 |
|------|------|
| 待分析 | 等待 AI 分析 |
| 分析中 | AI 正在分析 |
| 待审核 | 方案等待审核 |
| 进行中 | 开发进行中 |
| 已完成 | 需求已完成 |
| 已关闭 | 需求已关闭 |

### 2.4 批量操作

1. 勾选多个需求
2. 点击 **"批量操作"**
3. 选择操作：
   - 批量分析
   - 修改状态
   - 分配负责人

## 3. AI 对话

### 3.1 开始对话

1. 在需求详情页点击 **"AI 助手"**
2. 输入您的问题或指令
3. 等待 AI 响应

### 3.2 对话技巧

**有效提问：**
- ✅ "这个 Bug 的根本原因是什么？"
- ✅ "请详细解释这个功能的实现方案"
- ❌ "修复它"（过于模糊）

**提供上下文：**
- 附加相关日志
- 说明复现步骤
- 提供错误截图

### 3.3 历史对话

- 对话历史自动保存
- 可以查看和继续之前的对话
- 支持导出对话记录

## 4. 审核操作

### 4.1 进入审核工作台

1. 点击顶部导航 **"审核"**
2. 查看待审核列表

### 4.2 审核方案

1. 点击进入方案详情
2. 仔细阅读方案内容
3. 选择审核决策：
   - **通过**：方案可执行
   - **需修改**：需要调整
   - **拒绝**：方案不可行
4. 填写审核意见
5. 提交审核

### 4.3 添加批注

1. 在方案内容中选中文本
2. 点击 **"添加批注"**
3. 输入批注内容
4. 保存

### 4.4 审核通知

- 新审核任务会发送通知
- 临近超时会提醒
- 审核完成通知方案创建者

## 5. 代码操作

### 5.1 查看代码

1. 进入代码生成结果页
2. 查看文件列表
3. 点击文件查看代码

### 5.2 代码 Diff

- 新增行显示为绿色
- 删除行显示为红色
- 修改行显示变更内容

### 5.3 应用代码

1. 审查代码变更
2. 点击 **"应用代码"**
3. 选择操作：
   - 创建新分支
   - 直接提交
4. 确认应用

### 5.4 创建 PR

应用代码后：
1. 系统自动创建 PR
2. 可以在 GitHub/GitLab 查看
3. 进行 Code Review

## 6. 测试操作

### 6.1 运行测试

1. 代码应用后自动运行
2. 也可手动触发：点击 **"运行测试"**

### 6.2 查看结果

测试结果页显示：
- 测试汇总（通过/失败/跳过）
- 覆盖率报告
- 失败详情

### 6.3 失败处理

对于失败的测试：
1. 查看错误信息
2. 查看 AI 分析的原因
3. 修复后重新运行

## 7. 知识库管理

### 7.1 上传文档

1. 进入 **知识库**
2. 点击 **"上传文档"**
3. 选择文件（支持 MD、PDF、DOCX）
4. 上传完成

### 7.2 管理文档

- 查看文档列表
- 编辑文档信息
- 删除文档
- 更新文档内容

### 7.3 文档分类

- 按类型分类（架构、API、业务）
- 按模块分类
- 添加标签

## 8. 系统设置

### 8.1 个人设置

- 修改密码
- 通知偏好
- 主题设置

### 8.2 团队管理

（管理员功能）
- 添加/删除成员
- 设置权限
- 分配角色

### 8.3 集成配置

- Jira 集成
- GitHub 集成
- Slack 通知

## 9. 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + K` | 全局搜索 |
| `Ctrl + N` | 新建需求 |
| `Ctrl + Enter` | 发送消息 |
| `Esc` | 关闭弹窗 |

## 10. 常见操作问题

### Q: 需求分析很慢？

AI 分析通常需要 10-30 秒，复杂需求可能更长。

### Q: 审核超时了？

超时的审核会自动转给备选审核人。

### Q: 代码生成失败？

检查方案描述是否足够详细，或尝试重新生成。
