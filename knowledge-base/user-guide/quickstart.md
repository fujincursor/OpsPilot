# 快速入门指南

## 1. 欢迎使用 OpsPilot

OpsPilot 是一个智能研发流程自动化平台，帮助您自动化需求分析、Bug 修复、功能设计等研发任务。

## 2. 首次登录

### 2.1 访问系统

打开浏览器，访问：
- 本地部署：http://localhost:3000
- 生产环境：https://your-domain.com

### 2.2 登录账号

使用管理员提供的账号密码登录，或注册新账号。

### 2.3 首页概览

登录后您将看到：
- **项目列表**：您参与的项目
- **待处理任务**：需要您处理的审核任务
- **最近活动**：系统最近的操作记录

## 3. 创建第一个项目

### 3.1 新建项目

1. 点击 **"新建项目"** 按钮
2. 填写项目信息：
   - 项目名称
   - 项目描述
   - 代码仓库地址（可选）
3. 点击 **"创建"**

### 3.2 配置项目

创建后，进入项目设置：
- **基础信息**：编辑项目名称、描述
- **AI 配置**：选择使用的 AI 模型
- **审核配置**：设置审核规则
- **知识库**：上传项目相关文档

## 4. 导入需求

### 4.1 手动创建

1. 进入项目
2. 点击 **"新建需求"**
3. 填写需求信息：
   - 标题
   - 描述
   - 类型（Bug/Feature/Task）
   - 优先级

### 4.2 从 Jira 导入

1. 进入 **设置 > 集成**
2. 配置 Jira 连接
3. 点击 **"同步需求"**

### 4.3 从 GitHub Issues 导入

1. 进入 **设置 > 集成**
2. 配置 GitHub 连接
3. 选择要同步的仓库

## 5. 使用 AI 分析需求

### 5.1 启动分析

1. 在需求列表中选择一个需求
2. 点击 **"AI 分析"**
3. 等待 AI 完成分析

### 5.2 查看分析结果

AI 会提供：
- **需求类型**：Bug/Feature
- **影响分析**：涉及的模块和范围
- **复杂度评估**：工作量估算
- **建议优先级**

### 5.3 与 AI 对话

您可以：
- 追问更多细节
- 要求补充分析
- 提供额外上下文

## 6. 生成解决方案

### 6.1 Bug 修复方案

对于 Bug 类型需求：
1. 点击 **"生成修复方案"**
2. AI 会分析根因并生成修复方案
3. 方案包括：
   - 根因分析
   - 修复步骤
   - 代码变更建议
   - 测试计划

### 6.2 功能设计方案

对于 Feature 类型需求：
1. 点击 **"生成设计方案"**
2. AI 会生成功能设计
3. 方案包括：
   - 功能概述
   - 技术方案
   - API 设计
   - 数据模型

## 7. 审核方案

### 7.1 进入审核

方案生成后会进入审核队列。

### 7.2 审核操作

审核人可以：
- **通过**：方案合理，可以执行
- **需修改**：方案需要调整
- **拒绝**：方案不可行

### 7.3 添加批注

可以对方案的具体部分添加评论。

## 8. 生成代码

### 8.1 触发代码生成

方案通过后：
1. 点击 **"生成代码"**
2. AI 自动生成代码

### 8.2 预览代码

在代码预览页面：
- 查看生成的文件
- 查看 Diff 对比
- 查看质量报告

### 8.3 应用代码

确认无误后：
1. 点击 **"应用代码"**
2. 选择创建分支或直接提交
3. 系统自动创建 PR

## 9. 运行测试

### 9.1 自动测试

代码应用后自动运行测试：
- 单元测试
- 集成测试
- 代码质量检查

### 9.2 查看结果

测试结果显示：
- 通过/失败数量
- 代码覆盖率
- 失败原因分析

## 10. 最佳实践

### 10.1 需求描述

- 描述要清晰具体
- 包含复现步骤（Bug）
- 说明预期行为

### 10.2 审核流程

- 及时处理审核任务
- 提供有建设性的反馈
- 关注风险点

### 10.3 代码审查

- 审查生成的代码
- 检查边界情况
- 验证测试覆盖

## 11. 获取帮助

- **文档中心**：查看详细文档
- **FAQ**：常见问题解答
- **技术支持**：联系支持团队
