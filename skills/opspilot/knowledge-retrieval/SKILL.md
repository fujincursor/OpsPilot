# 知识检索技能 (Knowledge Retrieval Skill)

## 概述

此技能提供运维知识库的智能检索能力，支持从项目文档、历史 Issue、代码注释、运维手册等多种来源获取相关知识，辅助问题分析和方案设计。

## 适用场景

- 分析需求时查询相似历史案例
- 设计方案时参考最佳实践
- 解决问题时查找解决方案
- 学习项目时了解背景知识

## 知识来源

### 1. 项目文档

```
文档类型：
├── README.md          # 项目说明
├── docs/
│   ├── architecture/  # 架构文档
│   ├── api/           # API 文档
│   ├── guides/        # 使用指南
│   └── runbooks/      # 运维手册
└── CHANGELOG.md       # 变更日志
```

### 2. Issue 历史

- GitHub Issues
- Jira 工单
- 内部 Bug 追踪系统

### 3. 代码知识

- 代码注释
- 函数文档字符串
- 类型定义
- 配置文件说明

### 4. 运维知识

- 告警处理手册
- 故障排查指南
- 部署流程文档
- 监控指标说明

## 检索流程

### 第一阶段：理解查询

1. **查询分析**
   - 提取关键词
   - 识别查询意图
   - 确定知识类型

2. **查询扩展**
   - 同义词扩展
   - 相关概念补充
   - 时间范围限定

### 第二阶段：多源检索

1. **向量检索**
   ```
   使用嵌入模型进行语义搜索
   - 相似度阈值：0.7
   - 返回数量：10
   - 重排序：按相关性
   ```

2. **关键词检索**
   - 全文搜索
   - 标签匹配
   - 精确匹配

3. **结构化查询**
   - 数据库查询
   - API 调用
   - 日志搜索

### 第三阶段：结果整合

1. **去重合并**
   - 相同内容去重
   - 版本选择最新
   - 来源标注

2. **相关性排序**
   - 语义相关性
   - 时间新鲜度
   - 来源权威性

3. **摘要生成**
   - 提取关键信息
   - 生成简明摘要
   - 保留引用链接

## 知识库管理

### 索引更新

```yaml
index_schedule:
  documents: 
    frequency: daily
    trigger: on_change
  
  issues:
    frequency: hourly
    trigger: on_close
  
  code:
    frequency: on_commit
    branches: [main, develop]
```

### 知识质量

1. **准确性验证**
   - 过期内容标记
   - 版本一致性检查
   - 引用有效性验证

2. **覆盖度分析**
   - 知识盲区识别
   - 文档完整性评估
   - 更新优先级建议

### 知识贡献

1. **自动学习**
   - 从解决的 Issue 学习
   - 从代码变更学习
   - 从用户反馈学习

2. **人工补充**
   - 专家知识录入
   - 最佳实践总结
   - 案例库更新

## 检索优化

### 查询优化技巧

```
✅ 有效的查询：
- "用户登录失败 401 错误" → 具体问题
- "Redis 连接池配置最佳实践" → 明确需求
- "2024年 API 限流变更" → 时间限定

❌ 无效的查询：
- "出错了" → 太模糊
- "怎么办" → 缺少上下文
- "所有文档" → 范围太大
```

### 结果质量提升

1. **反馈学习**
   - 记录用户选择
   - 分析点击行为
   - 优化排序模型

2. **缓存策略**
   - 热门查询缓存
   - 结果预计算
   - 增量更新

## 与其他技能的协作

- 为 `requirement-analysis` 提供历史案例
- 为 `bugfix-solution` 提供解决方案参考
- 为 `feature-design` 提供最佳实践
- 为 `test-execution` 提供测试用例参考
- 从各技能的执行结果中学习新知识
