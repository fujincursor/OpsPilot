# M9 - 测试用例生成与执行 · 页面原型说明

本文档描述 M9 模块各页面的**原型结构、布局、组件与交互**，遵循 [页面原型风格规范.md](页面原型风格规范.md)。可配合 `docs/prototypes/m9/` 下的 HTML 静态原型查看效果。

---

## 1. 页面清单与路由

| 序号 | 页面名称 | 路由（示例） | 说明 |
|------|----------|--------------|------|
| P1 | 测试执行列表 | `/projects/:projectId/tickets/:ticketId/tests` 或 `/projects/:projectId/tests` | 按工单或项目维度的测试执行列表，筛选、重跑入口 |
| P2 | 测试报告详情 | `/projects/:projectId/test-runs/:testRunId` | 单次执行的报告摘要、用例列表、原始报告下载 |

---

## 2. 全局布局（所有页面共用）

- **顶栏**：高度 56px，背景 #FFFFFF，下边框 1px #E5E7EB；左侧 Logo +「运维 Agent 工作台」；右侧「项目管理」「工作台」导航 + 用户头像下拉（退出等）。
- **侧栏**：宽度 220px，背景 #FFFFFF，右边框 1px #E5E7EB；当前项目下展示「概览」「需求」「测试」「设置」等子导航；可从工单详情或「测试」入口进入 M9 页面。
- **主内容区**：背景 #F9FAFB，左侧留白 24px，右侧留白 24px，上留白 24px；内容最大宽度 1200px（列表与详情页）。
- **规范引用**：字体、主色、按钮、卡片、表格均按《页面原型风格规范》执行。

## 3. P1 - 测试执行列表

### 3.1 布局

- 主内容区顶部：面包屑「项目管理 / 项目名 / 工单 #xxx / 测试」或「项目管理 / 项目名 / 测试执行」；标题「测试执行」H1（20px，字重 600）。
- 下方：筛选栏（按工单、状态、时间）+「执行测试」主按钮（在工单维度下显示；若为项目维度则可为「全部测试」入口）；再下方为表格区域（卡片容器，白底，圆角 8px，内边距 24px）。

### 3.2 筛选栏

- **工单**：单行输入或下拉（工单 ID/标题），占位符「搜索工单」；在项目维度下列表需带工单信息。
- **状态**：下拉，选项「全部」「执行中」「通过」「失败」，默认「全部」。
- **时间范围**：可选，起止日期；默认最近 7 天或全部。
- **查询**：次要按钮「查询」；「重置」链接样式。
- 与表格间距 16px。

### 3.3 表格

| 列名 | 宽度 | 说明 |
|------|------|------|
| 工单 | 自适应 | 工单标题 + ID，可点击进入工单详情；在工单维度下可省略此列 |
| 执行时间 | 160px | 开始时间或「执行中」 |
| 状态 | 100px | 标签：执行中（蓝/黄）、通过（绿）、失败（红） |
| 通过率 | 100px | 如「8/10」或「80%」；执行中显示「-」 |
| 操作 | 140px | 「查看报告」链接；失败时显示「重跑」按钮 |

- 表头背景 #F9FAFB，表头文字 14px 字重 600；行高约 52px；无数据时显示空状态插画 +「暂无测试执行记录，可点击执行测试」。
- 底部分页：总数、每页条数选择（10/20/50）、上一页/下一页。

### 3.4 交互

- 点击「执行测试」→ 调用触发接口，创建 TestRun，Toast「测试已开始执行」，列表刷新或跳转至该次执行详情（P2）。
- 点击「查看报告」→ 跳转 P2。
- 点击「重跑」→ 二次确认「确定重新执行测试？」确认后调用触发接口，列表刷新。

## 4. P2 - 测试报告详情

### 4.1 布局

- 顶部：面包屑「项目管理 / 项目名 / 工单 #xxx / 测试 / 报告」；标题区左侧为「测试报告」H1，右侧为状态标签（通过/失败/执行中）+ 操作「重新执行」按钮（失败时显示）、「下载原始报告」链接（有 rawReportUrl 时显示）。
- 下方：摘要卡片（一行统计：总数、通过、失败、跳过、耗时）；再下方为用例结果表格（卡片容器）。

### 4.2 摘要卡片

- 横向排列：**总用例数**、**通过**、**失败**、**跳过**、**耗时**（如 12.3s）；失败数用错误色强调，通过用成功色。
- 可选：简短 summary 文案（如「全部通过」或「2 个用例失败」）。

### 4.3 用例结果表格

| 列名 | 宽度 | 说明 |
|------|------|------|
| 用例名称 | 自适应 | name，可展开查看 message |
| 状态 | 100px | 标签：通过（绿）/ 失败（红）/ 跳过（灰） |
| 耗时 | 80px | 秒数 |
| 说明/错误 | 自适应 | 失败时显示 message 或截断；可「展开」看完整堆栈 |
| 操作 | 80px | 有 logUrl 时「日志」链接 |

- 表头背景 #F9FAFB；失败行可用浅红底或左侧色条标识。
- 执行中状态：表格显示「执行中，请稍后刷新」或轮询/WebSocket 更新。

### 4.4 交互

- 「重新执行」→ 同 P1 重跑，确认后触发新 TestRun，可跳转新报告或留在当前页提示「已提交重跑」。
- 「下载原始报告」→ 新窗口打开 rawReportUrl 或下载文件。
- 失败用例行可展开查看完整 message/堆栈。

---

## 5. 与工单/项目入口的衔接

- **工单详情页**：工单详情内「测试」Tab 展示该工单下的测试执行列表（即 P1 工单维度），并提供「执行测试」按钮；点击某次执行进入 P2。
- **项目/工作台**：可提供「测试执行」主导航或「最近测试」入口，进入 P1 项目维度列表（带工单列），再进入 P2。
