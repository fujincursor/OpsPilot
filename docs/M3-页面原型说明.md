# M3 - 知识库与系统理解增强 · 页面原型说明

本文档描述 M3 模块各页面的**原型结构、布局、组件与交互**，遵循 [页面原型风格规范.md](页面原型风格规范.md)。可配合 `docs/prototypes/m3/` 下的 HTML 静态原型查看效果。

---

## 1. 页面清单与路由

| 序号 | 页面名称 | 路由（示例） | 说明 |
|------|----------|--------------|------|
| P1 | 知识库概览 | `/projects/:id/knowledge` | 文档统计、索引状态、快捷入口 |
| P2 | 文档列表 | `/projects/:id/knowledge/docs` | 分页列表、筛选、上传、触发索引 |
| P3 | 新建/上传文档 | `/projects/:id/knowledge/docs/new` | 文档类型、标题、内容或文件上传 |
| P4 | 文档详情/编辑 | `/projects/:id/knowledge/docs/:docId` | 元数据、内容、索引状态、编辑 |
| P5 | 代码索引配置 | `/projects/:id/knowledge/code-index` | 包含/排除路径、触发方式、手动触发 |
| P6 | 索引任务列表 | `/projects/:id/knowledge/index-jobs` | 任务列表、状态、耗时、重试 |
| P7 | 知识库设置 | `/projects/:id/knowledge/settings` | 更新策略、Webhook、定时任务 |
| P8 | 检索测试（可选） | `/projects/:id/knowledge/search-test` | 输入 query 预览检索结果 |

## 2. 全局布局（所有页面共用）

- **顶栏**：高度 56px，背景 #FFFFFF，下边框 1px #E5E7EB；左侧 Logo +「运维 Agent 工作台」；右侧「项目管理」「工作台」导航 + 用户头像下拉。
- **侧栏**：宽度 220px，当前项目下展示「概览」「知识库」「需求」「设置」等；知识库子项为「文档」「代码索引」「索引任务」「设置」。
- **主内容区**：背景 #F9FAFB，边距 24px，内容最大宽度 1200px。
- **规范引用**：字体、主色、按钮、卡片、表格均按《页面原型风格规范》执行。

## 3. P1 - 知识库概览

### 3.1 布局

- 主内容区顶部：面包屑「项目管理 / 项目名 / 知识库」；标题「知识库」H1（20px，字重 600）。
- 下方为两列：左侧统计与状态卡片（约 2/3），右侧快捷操作卡片（约 1/3）。

### 3.2 左侧 - 统计与状态

- **文档统计卡片**：标题「文档概览」；内容：文档总数、按类型分布（项目信息 / 上传 / Runbook / 反馈摘要）；索引状态：已索引数 / 待索引 / 失败数；「查看文档列表」链接 → P2。
- **代码索引状态卡片**：是否已配置、最近一次全量/增量索引时间、状态（成功/失败/未执行）；「去配置」链接 → P5。

### 3.3 右侧 - 快捷操作

- **快捷操作**：主按钮「上传文档」→ P3；次要按钮「触发全量索引」→ 二次确认后调用触发接口；「索引任务」链接 → P6。
- **最近任务**：最近 3～5 条索引任务，显示类型（文档/代码）、范围（全量/增量）、状态、时间；「全部任务」→ P6。

### 3.4 交互

- 点击「上传文档」→ 跳转 P3。
- 点击「触发全量索引」→ 确认弹窗，确认后创建任务并跳转 P6 或刷新概览。
- 点击「去配置」→ 跳转 P5。

---

## 4. P2 - 文档列表

### 4.1 布局

- 标题「知识库文档」H1；右侧「上传文档」主按钮。
- 筛选栏：文档类型（下拉：全部/项目信息/上传/Runbook/反馈摘要）、状态（全部/待索引/已索引/失败）、关键词搜索（标题）；「查询」「重置」。
- 表格区域（卡片容器，白底，圆角 8px）。

### 4.2 表格

| 列名 | 宽度 | 说明 |
|------|------|------|
| 标题/名称 | 自适应 | 可点击进入详情；下方 12px 灰色显示 docType 标签 |
| 类型 | 100px | 标签：项目信息/上传/Runbook/反馈摘要 |
| 状态 | 90px | 待索引（黄）/ 已索引（绿）/ 失败（红） |
| 索引时间 | 120px | indexedAt，12px 灰色 |
| 更新时间 | 120px | updatedAt，12px 灰色 |
| 操作 | 140px | 「查看」「编辑」「删除」；删除需二次确认 |

- 表头背景 #F9FAFB；行高约 52px；无数据时空状态「暂无文档，点击上传文档」。
- 底部分页：总数、每页条数、上一页/下一页。

### 4.3 交互

- 「上传文档」→ P3。
- 点击标题或「查看」→ P4。
- 「编辑」→ P4 编辑态。
- 「删除」→ 确认弹窗，确认后调用删除接口并刷新列表。
- 列表上方可选「批量触发索引」：勾选待索引/失败项后，按钮「重新索引」调用触发接口。

## 5. P3 - 新建/上传文档

### 5.1 布局

- 标题「上传文档」或「新建文档」H1；单列表单卡片，最大宽度 640px。

### 5.2 表单项

| 标签 | 控件 | 必填 | 说明 |
|------|------|------|------|
| 文档类型 | 下拉 | 是 | 项目信息 / 上传 / Runbook / 其他 |
| 标题 | 单行输入 | 是 | 占位符「请输入文档标题」 |
| 内容 | 多行文本 | 与「文件上传」二选一 | 4～8 行，占位符「粘贴或输入文档内容」 |
| 文件上传 | 文件选择 | 与「内容」二选一 | 支持 .md / .txt / .pdf（按产品能力）；上传后解析为内容或仅存引用 |

- 表单项间距 16px；标签与输入框间距 8px。

### 5.3 底部操作

- 「取消」次要按钮 → 返回 P2。
- 「保存并索引」主按钮 → 提交后创建文档并加入索引队列；成功提示「文档已保存，正在索引」并跳转 P2 或 P4。

### 5.4 校验与提示

- 标题必填；内容与文件至少填一项；类型必选。提交失败时在表单上方或字段旁展示错误信息（错误色）。

## 6. P4 - 文档详情/编辑

### 6.1 布局

- 顶部：面包屑「知识库 / 文档 / 标题」；标题 H1 + 状态标签（待索引/已索引/失败）；右侧「编辑」次要按钮（编辑态时为「保存」「取消」）。
- 下方两列：左侧文档内容区（卡片，可只读或可编辑多行文本）；右侧元数据卡片。

### 6.2 左侧 - 内容区

- 只读态：卡片内展示文档内容（支持简单 Markdown 或纯文本展示）。
- 编辑态：多行输入框替代展示区，保存后触发重新索引，状态变为待索引。

### 6.3 右侧 - 元数据

- 文档类型、创建时间、更新时间、最近索引时间；若状态为失败，显示失败原因（可来自 IndexJob 或 doc 的 message）。
- 操作：「重新索引」链接（仅待索引或失败时有效）；「删除」危险链接，二次确认后删除并返回 P2。

### 6.4 交互

- 「编辑」→ 进入编辑态；「保存」→ 提交更新并刷新；「取消」→ 恢复只读。
- 「重新索引」→ 调用单文档触发接口，状态刷新为待索引或 indexing。

## 7. P5 - 代码索引配置

### 7.1 布局

- 标题「代码索引」H2；表单卡片分块：「索引范围」「更新触发」「立即执行」。

### 7.2 索引范围

| 标签 | 控件 | 说明 |
|------|------|------|
| 包含路径 | 多行文本或标签输入 | 每行一个路径，如 src/、lib/；空表示全库 |
| 排除路径 | 多行文本或标签输入 | 如 node_modules/、*.min.js |

- 说明文字：12px 灰色「仅对指定路径下的代码建立索引，便于 Agent 检索项目结构与关键模块。」

### 7.3 更新触发

| 标签 | 控件 | 说明 |
|------|------|------|
| 触发方式 | 单选或下拉 | Webhook（MR 合并时）/ 定时 / 仅手动 |
| 定时表达式 | 输入 | 当选择「定时」时显示，cron 或简单描述（如「每日 2:00」） |

### 7.4 立即执行

- 「全量索引」主按钮：二次确认「将根据当前配置执行全量代码索引，可能耗时较久」，确认后创建 IndexJob，跳转 P6 或提示「任务已创建」。
- 「增量索引」次要按钮：可选，若支持则创建 scope=incremental 的任务。

### 7.5 操作

- 「保存配置」主按钮：仅保存 CodeIndexConfig，不执行任务；成功 Toast「配置已保存」。

---

## 8. P6 - 索引任务列表

### 8.1 布局

- 标题「索引任务」H2；筛选栏：任务类型（全部/文档/代码）、范围（全部/全量/增量）、状态（全部/运行中/成功/失败）；「查询」「重置」。
- 表格：任务 ID（可短显）、类型、范围、状态、开始时间、结束时间、耗时、统计（如文档数/分块数）；操作「查看」「重试」（仅失败时）。

### 8.2 任务详情（可选弹窗或子页）

- 任务详情：配置快照、执行日志摘要、stats（docCount、chunkCount 等）；失败时展示 message。

### 8.3 交互

- 「重试」→ 二次确认后重新提交同参数任务；列表刷新。
- 状态为「运行中」时，可轮询或自动刷新状态。

---

## 9. P7 - 知识库设置

### 9.1 布局

- 标题「知识库设置」H2；表单卡片：「更新策略」「默认行为」。

### 9.2 更新策略

| 标签 | 控件 | 说明 |
|------|------|------|
| MR 合并触发 | 开关 | 开启后，MR 合并时自动触发代码增量索引（需与 Git 集成） |
| 定时全量索引 | 开关 + 时间 | 如每日 2:00 执行文档+代码全量（可选） |
| 新文档默认索引 | 开关 | 新文档创建后是否自动加入索引队列（默认开） |

### 9.3 默认行为

- 检索默认 docTypes：多选（项目信息、上传、Runbook、反馈摘要），用于 Agent 检索时的默认过滤。
- 「保存」主按钮；成功 Toast「设置已保存」。

---

## 10. P8 - 检索测试（可选）

### 10.1 布局

- 标题「检索测试」H2；说明「输入查询内容，预览当前项目知识库检索结果，用于调试与验证。」。
- 输入区：查询文本（多行或单行）、topK（数字，默认 5）、文档类型（多选）；「检索」主按钮。
- 结果区：卡片列表，每条显示 docType、标题、snippet、score；无结果时提示「未命中任何文档」。

### 10.2 交互

- 点击「检索」→ 调用 Search 接口，展示 hits；仅用于调试，权限同项目成员。
