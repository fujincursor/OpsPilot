# Phase 2-1: Agent 执行监控 · 页面原型设计稿

基于 DeerFlow 架构，新增 **Agent 执行监控页面**，实时展示 Lead Agent 和 Sub-Agents 的执行状态、流程进度、资源消耗。本文档遵循 [页面原型风格规范.md](页面原型风格规范.md)。

---

## 1. 设计背景

### 1.1 设计目的

DeerFlow 架构中，Agent 执行过程对用户透明化：
- **可观测性**：实时查看 Agent 执行状态
- **可追溯性**：回溯执行历史和决策路径
- **可控性**：支持中断、重试等干预操作

### 1.2 监控维度

| 维度 | 说明 |
|------|------|
| **执行状态** | 各 Agent 当前状态（执行中/等待/完成/失败） |
| **流程进度** | 整体流程完成百分比 |
| **执行日志** | 实时执行日志流 |
| **资源消耗** | Token 消耗、API 调用次数、执行时间 |
| **知识引用** | RAG 检索记录和引用追踪 |

---

## 2. 页面清单与路由

| 序号 | 页面名称 | 路由 | 说明 |
|------|----------|------|------|
| P1 | 执行监控主页 | `/monitor` | 当前执行任务监控 |
| P2 | 任务详情 | `/monitor/tasks/:id` | 单个任务执行详情 |
| P3 | 执行历史 | `/monitor/history` | 历史执行记录 |
