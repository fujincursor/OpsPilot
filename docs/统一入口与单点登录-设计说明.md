# 统一入口与单点登录 - 设计说明

本文档描述运维 Agent 生产系统的**统一入口**与**单点登录（SSO）**能力，用于整合 M1～M9 九个模块，实现一次登录、全站通行与统一工作台导航。

---

## 1. 目标

- **单点登录**：用户在一次认证后，可访问其有权限的全部模块（M1～M9），无需在各模块重复登录。
- **统一入口**：提供统一工作台/门户页，集中展示各模块入口与功能描述，便于按角色与任务进入对应模块。
- **风格一致**：入口页、登录页与各模块页面原型遵循 [页面原型风格规范](页面原型风格规范.md)，视觉与交互统一。

---

## 2. 单点登录（SSO）能力说明

### 2.1 职责边界

- **认证（Authentication）**：由统一认证层完成（如企业 IdP、OAuth2/OIDC、自建登录），签发 Token（如 JWT）或 Session；本系统不实现账号密码存储与校验，仅校验 Token 或与 IdP 建立信任。
- **授权（Authorization）**：本系统在 BFF/网关层根据 Token 解析出的 userId（及可选 tenantId、角色）与 M1 项目成员数据，判断用户可访问的项目与模块；各模块接口按项目/角色做权限校验。
- **会话**：登录态通过 Cookie（HttpOnly）或前端持有的 Token 传递；Token 过期前可刷新或重新向 IdP 发起静默登录。

### 2.2 与各模块的整合方式

- **统一网关/BFF**：所有请求经同一域名与网关，网关负责校验登录态、注入 userId，并将请求路由到对应模块或后端服务。
- **模块内不再单独登录**：M1～M9 的前端页面不提供独立登录表单；未登录用户访问任意模块时，重定向到统一登录页，登录成功后可选重定向回原访问地址或统一入口。
- **按权限展示入口**：统一入口页仅展示当前用户有权限的模块（如系统管理员可见全部，项目成员可见其所属项目相关模块）；原型阶段可展示全部 9 个模块入口与功能描述。

### 2.3 典型流程（示意）

1. 用户打开系统任意 URL → 网关/BFF 校验无有效 Token → 重定向到**统一登录页**。
2. 用户在登录页完成认证（或通过企业 SSO 跳转）→ 认证成功后写 Cookie/返回 Token，重定向到**统一入口页（工作台）**。
3. 用户在入口页选择模块（如「项目管理」「需求工单」「Review 工作台」）→ 跳转至对应模块首屏；后续在模块内跳转不再重复认证。
4. Token 过期后，接口返回 401 → 前端清除本地状态并重定向到统一登录页。

## 3. 统一入口页

### 3.1 功能

- **模块入口**：展示 M1～M9 共 9 个模块的入口卡片；每卡片包含：模块名称、简要功能描述、「进入」链接。
- **功能描述**：针对每个模块提供一句话或短段描述，便于用户理解该模块用途与适用场景（见下表）。
- **导航**：顶栏展示产品名与当前用户信息；从入口页可进入各模块，各模块内可提供「返回工作台」链接回到入口页。

### 3.2 各模块功能描述（用于入口页展示）

| 模块 | 模块名称 | 功能描述 |
|------|----------|----------|
| M1 | 多项目与 Agent 实例管理 | 创建与管理运维项目，配置每个项目专属的 Agent 实例（模型、Prompt、工具链），管理项目成员与权限。 |
| M2 | 项目信息与知识库前置维护 | 维护项目概述、架构、目录结构、配置说明与 Runbook；完成知识库就绪后，该项目方可提交需求与 Bug。 |
| M3 | 知识库与系统理解增强 | 管理文档与代码索引，支持 RAG 检索与反馈写入，提升 Agent 对当前项目的理解能力。 |
| M4 | 需求理解与分类 | 提交日常运维需求，由 Agent 自动分析并分类为 Bug 或新需求，并驱动后续修复或设计流程。 |
| M5 | Bug 修复流程 | 查看 Bug 工单、生成与查看修复方案，经 Review 后进入代码生成与测试。 |
| M6 | 新需求设计流程 | 查看新需求工单、生成与查看技术方案/设计文档，经 Review 后进入代码实现与测试。 |
| M7 | 人工 Review 工作台 | 对待审的方案、代码变更与测试报告进行通过/驳回操作，并查看 Review 历史与审计日志。 |
| M8 | 代码生成与语法校验 | 查看根据方案生成的代码变更，执行语法/静态检查，直至通过后进入测试。 |
| M9 | 测试用例生成与执行 | 查看测试用例与执行结果，查看测试报告，失败可重新执行或回退修复。 |

### 3.3 入口页与各模块原型的链接关系

- 入口页（工作台）→ 各模块**首屏**链接见 [入口页面原型说明](#4-入口页面原型) 及 `docs/prototypes/README.md`。
- 各模块内可提供顶栏或侧栏「工作台」链接，指回统一入口页，形成闭环。

## 4. 入口页面原型

- **登录页**：`docs/prototypes/portal/login.html` — 模拟登录，提交后跳转至工作台（index.html）。
- **工作台（统一入口）**：`docs/prototypes/portal/index.html` — 展示 9 个模块卡片及功能描述，链接至各模块原型首屏。
- **样式**：与 [页面原型风格规范](页面原型风格规范.md) 一致，使用 `portal/style.css`，与各模块风格统一。

详细页面结构、布局与交互见 [prototypes/portal/README.md](prototypes/portal/README.md)。全部原型索引见 [prototypes/README.md](prototypes/README.md)。
