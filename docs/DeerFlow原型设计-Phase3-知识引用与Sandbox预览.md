# Phase 3: 知识引用展示与 Sandbox 预览 · 页面原型设计稿

基于 DeerFlow 架构，优化 M3 知识库和 M8 代码生成模块，增加**知识引用追踪**和 **Sandbox 执行预览**。本文档遵循 [页面原型风格规范.md](页面原型风格规范.md)。

---

## 1. 设计背景

### 1.1 Phase 3 优化目标

| 模块 | 优化内容 | 价值 |
|------|----------|------|
| M3 知识库 | 增加引用追踪 | 了解知识被 Agent 使用情况 |
| M8 代码生成 | 增加 Sandbox 预览 | 可视化代码执行过程 |

### 1.2 与 DeerFlow 的关联

- **DeerMem**：长期记忆持久化，知识引用可追踪
- **Sandbox**：隔离执行环境，支持实时预览
