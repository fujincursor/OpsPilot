# Phase 1-2: HITL Approval Cards · 页面原型设计稿

基于 DeerFlow Middleware Chain 设计，将传统独立审批页面改为**内嵌在对话流中的审批卡片**。本文档遵循 [页面原型风格规范.md](页面原型风格规范.md)。

---

## 1. 设计背景

### 1.1 HITL (Human-in-the-Loop) 概念

DeerFlow 的 Middleware Chain 在关键节点插入人工审批环节：

```
Agent 执行 → [HITL 卡点] → 继续执行 → [HITL 卡点] → 完成
                 ↓                          ↓
            方案审批                    代码审批
```

### 1.2 与旧设计对比

| 维度 | 旧设计（M7 列表页） | 新设计（内嵌卡片） |
|------|-------------------|-------------------|
| 审批位置 | 独立 Review 列表页 | 对话流中内嵌 |
| 上下文 | 需跳转查看 | 上下文完整保留 |
| 操作方式 | 页面表单 | 卡片内一键操作 |
| 通知机制 | 列表提醒 | IM 推送 + 超时升级 |

### 1.3 审批卡点类型

| 卡点 | 触发时机 | 审批内容 |
|------|----------|----------|
| **方案审批** | Bug Fix / Feature Design 完成 | 修复方案 / 设计文档 |
| **代码审批** | Code Generation 完成 | 代码变更 + Lint 结果 |
| **测试审批** | Test Execution 完成 | 测试报告 |
| **部署审批** | 准备发布时（可选） | 发布计划 |

## 2. Approval Card 通用结构

### 2.1 卡片基础结构

```
┌──────────────────────────────────────────────────────────────────────┐
│                                                                      │
│ ┌──────────────────────────────────────────────────────────────────┐ │
│ │ [图标] [标题]                                    [状态标签]      │ │
│ ├──────────────────────────────────────────────────────────────────┤ │
│ │                                                                  │ │
│ │ [审批内容区域]                                                   │ │
│ │                                                                  │ │
│ ├──────────────────────────────────────────────────────────────────┤ │
│ │ [元信息区域: 工单号、提交人、提交时间等]                         │ │
│ ├──────────────────────────────────────────────────────────────────┤ │
│ │ [操作区域: 通过、驳回、评论等]                                   │ │
│ └──────────────────────────────────────────────────────────────────┘ │
│ 🔧 Bug Fix Agent · 10:35                                             │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

### 2.2 卡片状态

| 状态 | 标签样式 | 操作区 |
|------|----------|--------|
| `pending` 待审批 | 🟡 橙色 | 显示通过/驳回按钮 |
| `approved` 已通过 | 🟢 绿色 | 显示审批结果 |
| `rejected` 已驳回 | 🔴 红色 | 显示驳回原因 |
| `timeout` 已超时 | ⚪ 灰色 | 显示超时升级信息 |
| `expired` 已过期 | ⚪ 灰色 | 显示过期提示 |
