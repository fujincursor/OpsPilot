# M1 - 多项目与 Agent 实例管理 · 页面原型说明

本文档描述 M1 模块各页面的**原型结构、布局、组件与交互**，遵循 [页面原型风格规范.md](页面原型风格规范.md)。可配合 `docs/prototypes/m1/` 下的 HTML 静态原型查看效果。

---

## 1. 页面清单与路由

| 序号 | 页面名称 | 路由（示例） | 说明 |
|------|----------|--------------|------|
| P1 | 项目列表 | `/projects` | 分页列表、筛选、新建入口 |
| P2 | 新建项目 | `/projects/new` | 创建项目表单 |
| P3 | 项目详情/概览 | `/projects/:id` | 基本信息、状态、快捷入口 |
| P4 | 项目设置 - 基本信息 | `/projects/:id/settings/basic` | 编辑项目基本信息 |
| P5 | 项目设置 - Agent 配置 | `/projects/:id/settings/agent` | 模型、Prompt、工具链配置 |
| P6 | 项目设置 - 成员管理 | `/projects/:id/settings/members` | 成员列表、添加、角色、移除 |
| P7 | 项目设置 - 高级 | `/projects/:id/settings/advanced` | 归档等操作 |

---

## 2. 全局布局（所有页面共用）

- **顶栏**：高度 56px，背景 #FFFFFF，下边框 1px #E5E7EB；左侧 Logo +「运维 Agent 工作台」；右侧「项目管理」「工作台」导航 + 用户头像下拉（退出等）。
- **侧栏**：宽度 220px，背景 #FFFFFF，右边框 1px #E5E7EB；当前项目下展示「概览」「需求」「设置」等子导航；无项目时仅展示「项目列表」。
- **主内容区**：背景 #F9FAFB，左侧留白 24px，右侧留白 24px，上留白 24px；内容最大宽度 1200px（列表与表单页）。
- **规范引用**：字体、主色、按钮、卡片、表格均按《页面原型风格规范》执行。

---

## 3. P1 - 项目列表

### 3.1 布局

- 主内容区顶部：标题「项目管理」H1（20px，字重 600）。
- 下方：筛选栏 +「新建项目」主按钮（右对齐）；再下方为表格区域（卡片容器，白底，圆角 8px，内边距 24px）。

### 3.2 筛选栏

- **项目名称**：单行输入框，占位符「搜索项目名称」，宽度 200px。
- **状态**：下拉，选项「全部」「启用」「已归档」，默认「全部」。
- **查询**：次要按钮「查询」；「重置」链接样式。
- 与表格间距 16px。

### 3.3 表格

| 列名 | 宽度 | 说明 |
|------|------|------|
| 项目名称 | 自适应 | 可点击进入项目详情；下方小字 12px 灰色显示 repoUrl 截断 |
| 环境类型 | 80px | 标签形式：dev/test/pre/prod |
| 状态 | 80px | 标签：启用（绿）/ 已归档（灰） |
| 知识库就绪 | 100px | 是/否（来自 M2，可后续对接） |
| 更新时间 | 120px | 日期时间，12px 灰色 |
| 操作 | 140px | 「进入」「设置」链接；「归档」仅 admin 且项目为启用时显示 |

- 表头背景 #F9FAFB，表头文字 14px 字重 600；行高约 52px；无数据时显示空状态插画 +「暂无项目，点击新建项目」。
- 底部分页：总数、每页条数选择（10/20/50）、上一页/下一页。

### 3.4 交互

- 点击「新建项目」→ 跳转 P2。
- 点击项目名称或「进入」→ 跳转 P3。
- 点击「设置」→ 跳转 P4（或设置首页再选 Tab）。
- 点击「归档」→ 二次确认弹窗，确认后调用归档接口，列表刷新。

## 4. P2 - 新建项目

### 4.1 布局

- 主内容区：标题「新建项目」H1；下方单列表单卡片，最大宽度 560px，卡片内边距 24px。

### 4.2 表单项（自上而下）

| 标签 | 控件 | 必填 | 说明 |
|------|------|------|------|
| 项目名称 | 单行输入 | 是 | 占位符「请输入项目名称」 |
| 项目简介 | 多行文本 | 否 | 2～4 行，占位符「选填」 |
| 代码库地址 | 单行输入 | 是 | 占位符「如 https://github.com/org/repo.git」 |
| 默认分支 | 单行输入 | 否 | 默认值 main，占位符「main」 |
| 环境类型 | 下拉 | 否 | 选项：开发 / 测试 / 预发 / 生产 |

- 表单项间距 16px；标签与输入框间距 8px。

### 4.3 底部操作

- 「取消」次要按钮 → 返回 P1。
- 「创建」主按钮 → 提交表单；成功后跳转 P3 或 P4，并提示「项目已创建，请完善知识库与 Agent 配置」。

### 4.4 校验与提示

- 项目名称、代码库地址必填；名称格式与唯一性由后端校验，前端可做非空与格式提示。
- 提交失败时在表单上方或字段旁展示错误信息（错误色）。

## 5. P3 - 项目详情/概览

### 5.1 布局

- 顶部：项目名称 H1 + 状态标签（启用/已归档）；右侧「项目设置」次要按钮。
- 下方两列：左侧主信息区（约 2/3），右侧卡片区（约 1/3）。

### 5.2 左侧 - 基本信息卡片

- 卡片标题「基本信息」；内容：项目简介、代码库地址（可复制）、默认分支、环境类型、创建时间、更新时间；若为归档状态，显示提示「项目已归档，不可新建需求与修改配置」。

### 5.3 右侧 - 状态与快捷入口

- **Agent 配置状态**：卡片「Agent 配置」；简要显示是否已配置（是/否），「去配置」链接 → P5。
- **知识库就绪**：卡片「知识库」；显示是否就绪（来自 M2），「去维护」链接 → M2 知识库页（路由可另定）。
- **成员**：卡片「成员」；显示成员数量，「管理成员」链接 → P6。

### 5.4 交互

- 「项目设置」→ 跳转 P4 或设置默认 Tab。
- 归档状态下，「去配置」「去维护」等可置灰或提示先恢复。

---

## 6. P4 - 项目设置 - 基本信息

### 6.1 布局

- 顶部面包屑：项目管理 / 项目名 / 设置；或 Tab：基本信息 | Agent 配置 | 成员管理 | 高级。
- 主内容：标题「基本信息」H2；表单卡片，字段与 P2 一致（项目名称、简介、代码库地址、默认分支、环境类型），无「创建」为「保存」。

### 6.2 操作与交互

- 「保存」主按钮 → 提交更新，成功 Toast「保存成功」。
- 「取消」→ 返回 P3 或丢弃未保存修改。

---

## 7. P5 - 项目设置 - Agent 配置

### 7.1 布局

- 与 P4 共用设置 Tab；本页标题「Agent 配置」H2。
- 表单卡片分块：「模型配置」「Prompt 模板」「工具链配置」。

### 7.2 模型配置

| 标签 | 控件 | 说明 |
|------|------|------|
| 模型提供商 | 下拉 | 如：OpenAI / 国产 / 私有化 |
| 模型名称 | 单行输入或下拉 | 如 gpt-4、gpt-3.5-turbo |
| Temperature | 数字输入 0～2，步长 0.1 | 可选，默认 0.2 |

### 7.3 Prompt 模板

- 下拉选择已配置的模板（来自 Prompt 表或配置中心）；或「从零编辑」链接打开内嵌/弹窗编辑器（多行文本）。
- 说明文字：12px 灰色「用于需求分析、方案生成的系统 Prompt」。

### 7.4 工具链配置

- 可配置项示例：Linter 类型（ESLint/Pylint 等）、测试框架（pytest/Jest 等）；以键值或简单表单展示，具体字段与后端 toolchainConfig 一致。
- 可「展开高级」收纳更多配置项。

### 7.5 操作

- 「保存」主按钮；成功提示「Agent 配置已更新」。

---

## 8. P6 - 项目设置 - 成员管理

### 8.1 布局

- 标题「成员管理」H2；右侧「添加成员」主按钮。
- 表格：成员列表，列：用户（ID 或昵称）、角色（标签：需求方/Review 方/管理员）、加入时间、操作（仅 admin 可「改角色」「移除」；最后一名 admin 不展示「移除」或禁用）。

### 8.2 添加成员

- 点击「添加成员」→ 弹窗：用户选择（输入 userId 或从组织架构选择）、角色下拉；「确定」「取消」。
- 添加成功后关闭弹窗并刷新列表。

### 8.3 改角色 / 移除

- 「改角色」→ 行内下拉或小弹窗选择新角色，保存。
- 「移除」→ 二次确认，确认后调用接口并刷新列表。

---

## 9. P7 - 项目设置 - 高级

### 9.1 布局

- 标题「高级」H2。
- 卡片「归档项目」：说明文案「归档后不可新建需求与修改配置，仅可查看。」；按钮「归档项目」危险按钮；点击后二次确认（输入项目名或勾选「我已了解后果」），确认后调用归档接口，跳转 P1 并提示「项目已归档」。

### 9.2 若产品支持恢复

- 若项目已归档，本页显示「恢复项目」次要按钮，确认后状态改为 active。
