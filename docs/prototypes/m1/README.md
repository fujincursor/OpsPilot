# M1 模块 - 页面原型

本目录为 **M1 多项目与 Agent 实例管理** 的静态 HTML 页面原型，样式遵循 [《页面原型风格规范》](../../页面原型风格规范.md)。

## 如何查看

在浏览器中直接打开各 HTML 文件即可（建议从 `project-list.html` 进入）。

## 页面与文件对应

| 页面 | 文件 |
|------|------|
| P1 项目列表 | [project-list.html](project-list.html) |
| P2 新建项目 | [project-new.html](project-new.html) |
| P3 项目详情/概览 | [project-detail.html](project-detail.html) |
| P4 项目设置 - 基本信息 | [project-settings-basic.html](project-settings-basic.html) |
| P5 项目设置 - Agent 配置 | [project-settings-agent.html](project-settings-agent.html) |
| P6 项目设置 - 成员管理 | [project-settings-members.html](project-settings-members.html) |
| P7 项目设置 - 高级 | [project-settings-advanced.html](project-settings-advanced.html) |

## 样式说明

- 共用样式：`style.css`（色彩、字体、间距、组件均按风格规范实现）
- 页面间通过 `<a href="...">` 链接跳转，便于按流程浏览

参见 [M1-页面原型说明.md](../../M1-页面原型说明.md)。
