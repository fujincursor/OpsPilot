# Phase 2-1: Agent 执行监控 · HTML 原型

本目录包含 DeerFlow 架构下 **Agent 执行监控**的 HTML 原型。

## 页面清单

| 页面 | 文件 | 说明 |
|------|------|------|
| 监控主页 | [index.html](index.html) | 任务概览与卡片列表 |
| 任务详情 | [task-detail.html](task-detail.html) | 执行流程图与详细日志 |

## 核心组件

### 1. 统计卡片
- 执行中 / 等待审批 / 今日完成 / 失败

### 2. 任务卡片
- 任务信息（类型、标题、状态）
- 执行进度条
- 时间信息
- 资源消耗统计
- 操作按钮

### 3. 执行流程图
- 节点状态（完成/执行中/等待）
- HITL 卡点标识
- 连接线状态

### 4. 执行日志
- 终端风格展示
- 时间戳 + Agent + 消息
- 实时刷新
