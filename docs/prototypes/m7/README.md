# M7 - 人工 Review 工作台 · 页面原型

本目录为 **M7 人工 Review 工作台** 的静态 HTML 原型，遵循 [《页面原型风格规范》](../../页面原型风格规范.md) 与 [M7-页面原型说明](../../M7-页面原型说明.md)。

## 文件说明

| 文件 | 说明 |
|------|------|
| style.css | 统一样式（色彩、字体、布局、表格、卡片、标签等） |
| review-list.html | 待审列表：按项目/类型筛选，进入详情 |
| review-detail-plan.html | Review 详情（方案）：FixPlan/DesignDoc 展示，通过/驳回，Review 历史 |
| review-detail-code.html | Review 详情（代码）：代码变更与 Lint 结果，通过/驳回，Review 历史 |
| review-detail-test.html | Review 详情（测试报告）：测试报告摘要，通过/驳回，Review 历史 |

## 使用方式

- 在浏览器中直接打开各 HTML 文件即可查看布局与样式。
- 交互（提交通过/驳回、筛选、分页等）以 [M7-页面原型说明](../../M7-页面原型说明.md) 与 [M7-人工Review工作台-详细设计](../../M7-人工Review工作台-详细设计.md) 为准，实际项目由前端框架实现。
