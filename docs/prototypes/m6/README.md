# M6 - 新需求设计流程 · 页面原型

本目录为 **M6 新需求设计流程** 模块的静态 HTML 页面原型，遵循 [页面原型风格规范](../../页面原型风格规范.md)，与 [M6-页面原型说明.md](../../M6-页面原型说明.md) 对应。

## 文件清单

| 文件 | 说明 |
|------|------|
| style.css | 统一样式（色彩、布局、组件） |
| feature-list.html | 新需求工单列表 |
| feature-detail.html | 新需求工单详情（工单信息 + 设计文档入口） |
| design-doc.html | 设计文档（已生成状态） |
| design-doc-empty.html | 设计文档（待生成） |
| design-doc-generating.html | 设计文档（生成中） |
| design-doc-failed.html | 设计文档（生成失败） |

## 使用方式

在浏览器中直接打开各 HTML 文件即可查看布局与样式；页面间通过相对链接跳转。交互逻辑以 [M6-页面原型说明.md](../../M6-页面原型说明.md) 为准，实际项目以前端框架实现为准。

## 与 M5 的对应关系

- M5（Bug 修复）：Bug 工单列表 → 工单详情 → 修复方案（根因 + 变更说明 + 建议文件）。
- M6（新需求设计）：需求工单列表 → 工单详情 → 设计文档（概述 + 模块划分 + 接口说明 + 建议文件）。
