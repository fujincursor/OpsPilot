# M9 模块 - 页面原型

本目录为 **M9 测试用例生成与执行** 的静态 HTML 页面原型，样式遵循 [《页面原型风格规范》](../../页面原型风格规范.md)。

## 如何查看

在浏览器中直接打开各 HTML 文件即可（建议从 `test-run-list.html` 进入）。

## 页面与文件对应

| 页面 | 文件 |
|------|------|
| P1 测试执行列表 | [test-run-list.html](test-run-list.html) |
| P2 测试报告详情 | [test-report-detail.html](test-report-detail.html) |

## 样式说明

- 共用样式：`style.css`（色彩、字体、间距、组件均按风格规范实现）
- 页面间通过 `<a href="...">` 链接跳转，便于按流程浏览

参见 [M9-页面原型说明.md](../../M9-页面原型说明.md)。
