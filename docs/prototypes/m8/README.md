# M8 代码生成与语法校验 - 页面原型

本目录为 M8 模块的静态 HTML 原型，遵循 [页面原型风格规范](../../页面原型风格规范.md) 与 [M8-页面原型说明.md](../../M8-页面原型说明.md)。

## 文件清单

| 文件 | 对应页面 |
|------|----------|
| code-change-list.html | P1 代码与校验列表 |
| code-change-detail-generating.html | P2 代码变更详情（生成中） |
| code-change-detail-passed.html | P3 代码变更详情（Lint 通过） |
| code-change-detail-failed.html | P4 代码变更详情（Lint 不通过） |
| style.css | 共用样式 |

在浏览器中直接打开各 HTML 文件即可查看布局与样式，交互以《M8-页面原型说明》为准。
