## 部署流程 1. 构建镜像：在项目根目录执行 `docker build -t ops-backend:latest .` 2. 推送至仓库：`docker push registry.example.com/ops-backend:latest` 3. 更新 K8s 部署：`kubectl set image deployment/ops-backend ops-backend=registry.example.com/ops-backend:latest -n prod` 4. 检查状态：`kubectl rollout status deployment/ops-backend -n prod` ## 回滚 执行 `kubectl rollout undo deployment/ops-backend -n prod` 可回滚至上一版本。
