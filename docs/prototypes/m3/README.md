# M3 知识库与系统理解增强 - 页面原型

本目录为 **M3 知识库与系统理解增强** 模块的静态 HTML 页面原型，遵循 [页面原型风格规范](../../页面原型风格规范.md)，与 [M3-页面原型说明.md](../../M3-页面原型说明.md) 对应。

## 文件说明

| 文件 | 对应页面 |
|------|----------|
| knowledge-overview.html | P1 知识库概览 |
| knowledge-doc-list.html | P2 文档列表 |
| knowledge-doc-new.html | P3 新建/上传文档 |
| knowledge-doc-detail.html | P4 文档详情/编辑 |
| knowledge-code-index.html | P5 代码索引配置 |
| knowledge-index-jobs.html | P6 索引任务列表 |
| knowledge-settings.html | P7 知识库设置 |
| knowledge-search-test.html | P8 检索测试（可选） |
| style.css | 统一样式（与规范一致） |

## 使用方式

在浏览器中直接打开各 HTML 文件即可查看布局与样式。页面间通过相对链接跳转，侧栏与顶栏为占位结构，实际项目需接入路由与权限。
