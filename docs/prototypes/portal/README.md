# 统一入口与登录 - 页面原型

本目录为 **OpsPilot 运维领航** 的**统一入口（工作台）**与**登录**静态原型，用于整合 M1～M9 各模块入口，并体现单点登录后的工作台导航。产品英文名 **OpsPilot**，中文名 **运维领航**。样式遵循 [《页面原型风格规范》](../../页面原型风格规范.md)，与各模块保持一致。

## 文件说明

| 文件 | 说明 |
|------|------|
| login.html | 统一登录页：模拟 SSO 登录，提交后跳转至工作台 |
| index.html | 工作台（统一入口）：展示 9 个模块卡片及功能描述，链接至各模块首屏 |
| style.css | 统一样式（与规范一致） |

## 各模块功能描述（入口页展示）

| 模块 | 功能描述 |
|------|----------|
| M1 多项目与 Agent 实例管理 | 创建与管理运维项目，配置每个项目专属的 Agent 实例（模型、Prompt、工具链），管理项目成员与权限。 |
| M2 项目信息与知识库前置维护 | 维护项目概述、架构、目录结构、配置说明与 Runbook；完成知识库就绪后，该项目方可提交需求与 Bug。 |
| M3 知识库与系统理解增强 | 管理文档与代码索引，支持 RAG 检索与反馈写入，提升 Agent 对当前项目的理解能力。 |
| M4 需求理解与分类 | 提交日常运维需求，由 Agent 自动分析并分类为 Bug 或新需求，并驱动后续修复或设计流程。 |
| M5 Bug 修复流程 | 查看 Bug 工单、生成与查看修复方案，经 Review 后进入代码生成与测试。 |
| M6 新需求设计流程 | 查看新需求工单、生成与查看技术方案/设计文档，经 Review 后进入代码实现与测试。 |
| M7 人工 Review 工作台 | 对待审的方案、代码变更与测试报告进行通过/驳回操作，并查看 Review 历史与审计日志。 |
| M8 代码生成与语法校验 | 查看根据方案生成的代码变更，执行语法/静态检查，直至通过后进入测试。 |
| M9 测试用例生成与执行 | 查看测试用例与执行结果，查看测试报告，失败可重新执行或回退修复。 |

## 使用方式

1. **推荐入口**：先打开 [login.html](login.html)，任意输入账号密码后点击「登录」，进入 [index.html](index.html) 工作台。
2. 在工作台点击各模块「进入」链接，跳转至对应模块原型首屏。
3. 各模块原型内可通过顶栏「工作台」或「项目管理」等返回；若需回到统一入口，可再次打开 `portal/index.html` 或从文档链接进入。
