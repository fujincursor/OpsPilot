# M6 - 新需求设计流程 · 页面原型说明

本文档描述 M6 模块各页面的**原型结构、布局、组件与交互**，遵循 [页面原型风格规范.md](页面原型风格规范.md)。可配合 `docs/prototypes/m6/` 下的 HTML 静态原型查看效果。

---

## 1. 页面清单与路由

| 序号 | 页面名称 | 路由（示例） | 说明 |
|------|----------|--------------|------|
| P1 | 新需求工单列表 | `/projects/:id/features` 或 `/workbench/features` | 分页列表、筛选、进入详情 |
| P2 | 新需求工单详情 | `/projects/:id/tickets/:ticketId` 或 `/features/:ticketId` | 工单信息、M4 分析结果、设计文档状态与入口 |
| P3 | 设计文档 | `/projects/:id/tickets/:ticketId/design` 或合并在 P2 内 Tab | 查看 DesignDoc、触发生成、重新生成 |

---

## 2. 全局布局（所有页面共用）

- **顶栏**：高度 56px，背景 #FFFFFF，下边框 1px #E5E7EB；左侧 Logo +「运维 Agent 工作台」；右侧「项目管理」「工作台」导航 + 用户头像下拉。
- **侧栏**：宽度 220px，背景 #FFFFFF，右边框 1px #E5E7EB；当前项目下展示「概览」「Bug 工单」「需求工单」「设置」等；无项目时展示「工作台首页」或从项目入口进入。
- **主内容区**：背景 #F9FAFB，左右留白 24px，上留白 24px；内容最大宽度 1200px。
- **规范引用**：字体、主色、按钮、卡片、表格均按《页面原型风格规范》执行。

---

## 3. P1 - 新需求工单列表

### 3.1 布局

- 主内容区顶部：标题「需求工单」H1（20px，字重 600）。
- 下方：筛选栏；再下方为表格区域（卡片容器，白底，圆角 8px，内边距 24px）。

### 3.2 筛选栏

- **项目**：下拉（若为跨项目工作台）或仅展示当前项目名。
- **工单标题/ID**：单行输入框，占位符「搜索工单标题或 ID」，宽度 200px。
- **设计状态**：下拉，选项「全部」「待生成」「已生成」「生成失败」，默认「全部」。
- **查询**：次要按钮「查询」；「重置」链接样式。
- 与表格间距 16px。

### 3.3 表格

| 列名 | 宽度 | 说明 |
|------|------|------|
| 工单标题 | 自适应 | 可点击进入工单详情；下方小字 12px 灰色显示工单 ID 或创建时间 |
| 项目 | 120px | 项目名称（跨项目时显示） |
| 分析结果 | 100px | 类型标签：新需求（来自 M4） |
| 设计状态 | 100px | 待生成 / 已生成 / 生成失败（对应 DesignDoc.status） |
| 更新时间 | 120px | 日期时间，12px 灰色 |
| 操作 | 140px | 「查看」「生成设计」链接 |

- 表头背景 #F9FAFB，表头文字 14px 字重 600；行高约 52px。
- 无数据时显示空状态插画 +「暂无新需求工单」。
- 底部分页：总数、每页条数（10/20/50）、上一页/下一页。

### 3.4 交互

- 点击工单标题或「查看」→ 跳转 P2。
- 点击「生成设计」→ 调用生成接口（可选先跳转 P2 再在 P3 触发生成），成功后刷新列表或跳转 P3。

## 4. P2 - 新需求工单详情

### 4.1 布局

- 顶部：面包屑「项目名 / 需求工单 / 工单标题」；或「返回列表」链接。
- 标题区：工单标题 H1 + 状态标签（待分析/已分析/设计待生成/设计已生成/已驳回等）。
- 下方 Tab 或分区：「工单信息」「设计文档」；默认展示工单信息，设计文档可独立 Tab 或同页下方区块。

### 4.2 工单信息区块

- **基本信息**：标题、描述、创建时间、创建人、项目（若单项目可省略）。
- **M4 分析结果**：类型（新需求）、范围摘要、涉及模块（若有）、置信度（若有）；以只读卡片展示。
- **设计文档入口**：若已有 DesignDoc 且 status=ready，显示「查看设计文档」主按钮或链接；若 status=generating，显示「设计生成中…」+ Loading；若 status=failed 或无 DesignDoc，显示「生成设计文档」主按钮。

### 4.3 交互

- 「生成设计文档」→ 调用 POST generate 接口，跳转或刷新至设计文档视图，展示 generating 或 ready。
- 「查看设计文档」→ 跳转 P3 或展开 P3 内容在同一页。

## 5. P3 - 设计文档

### 5.1 布局

- 顶部：面包屑「项目名 / 需求工单 / 工单标题 / 设计文档」；或与 P2 共用 Tab「设计文档」。
- 标题「设计文档」H2。

### 5.2 状态为「待生成」或「无设计」

- 说明文案：「基于工单与知识库上下文，由 Agent 生成技术方案与设计说明（模块划分、接口、数据流、涉及文件建议）。」
- 「生成设计文档」主按钮 → 触发生成；点击后按钮变为 Loading，文案「生成中…」。

### 5.3 状态为「生成中」（generating）

- 展示进度提示：图标 +「正在分析需求并生成设计文档，请稍候…」；可选进度条或骨架屏。

### 5.4 状态为「已生成」（ready）

- **设计概述**：卡片标题「设计概述」；正文展示 overview（多行文本）。
- **模块划分**：卡片标题「模块划分」；列表展示 modules 每项：模块名、说明、职责列表。
- **接口说明**：卡片标题「接口说明」；列表展示 interfaces 每项：接口名、方法、路径、说明（若有 dataFlow 可单独卡片展示）。
- **建议涉及文件**：卡片标题「建议涉及文件」；列表或标签展示 suggestedFiles。
- 底部操作：「重新生成」次要按钮（二次确认）；「去 Review」主按钮 → 跳转 M7 对应工单的 Review 任务（若 M7 已就绪）。

### 5.5 状态为「生成失败」（failed）

- 错误提示：alert 或卡片，错误色展示 errorMessage。
- 「重新生成」主按钮 → 再次调用生成接口。

### 5.6 交互汇总

- 生成 / 重新生成：调用 POST design/generate，轮询或 WebSocket 获取 DesignDoc 最新 status，更新展示。
- 「去 Review」：跳转 M7 工作台该工单的设计 Review 任务。

---

## 6. 与 M7、M8 的衔接说明

- **M7**：设计就绪后，待审项出现在 M7 工作台；用户可在 M7 对 DesignDoc 进行通过/驳回；本模块仅提供「查看设计」与「去 Review」入口，不实现 Review 操作。
- **M8**：Review 通过后由工作流触发 M8，无需在 M6 页面体现 M8 入口；若需在工单详情展示「代码生成」状态，可由工单统一状态或 BFF 聚合展示。

---

## 7. 原型文件与规范对应

- 色彩、字体、间距、按钮、表单、表格、卡片、顶栏侧栏均按《页面原型风格规范》执行。
- 静态 HTML 原型位于 `docs/prototypes/m6/`，可直接在浏览器中打开查看布局与样式，交互以说明为准；实际项目以前端框架实现为准。
