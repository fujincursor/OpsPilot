# Phase 2-2: Skills 与 Sandbox 配置 · 页面原型设计稿

基于 DeerFlow 架构，在 M1 项目设置中新增 **Skills 配置**和 **Sandbox 配置**页签。本文档遵循 [页面原型风格规范.md](页面原型风格规范.md)。

---

## 1. 设计背景

### 1.1 DeerFlow Skills 概念

Skills 是 DeerFlow 的可扩展能力模块：

```yaml
# Skills 定义示例
skills:
  - name: demand-analysis
    type: builtin
    description: 需求分析与分类
    
  - name: code-generation
    type: builtin
    description: 代码生成
    config:
      language: python
      style: google
      
  - name: custom-deploy
    type: custom
    description: 自定义部署技能
    script_path: /skills/deploy.py
```

### 1.2 DeerFlow Sandbox 概念

Sandbox 是隔离的代码执行环境：

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| Docker AIO | 本地 Docker 容器 | 开发/测试环境 |
| Kubernetes | K8s Pod | 生产环境 |
| E2B | 云端沙箱 | SaaS 服务 |
